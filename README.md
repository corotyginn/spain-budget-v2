# Интерактивный калькулятор бюджета на Испанию

Мой второй проект на Python. Это скрипт, который помогает рассчитать, сколько времени понадобится, чтобы накопить 5000 евро на переезд.

## Функционал
- Запрашивает у пользователя сумму накоплений в рублях.
- Запрашивает актуальный курс евро.
- Рассчитывает, сколько евро удастся накопить за месяц.
- Выводит количество месяцев до достижения цели.

## Технологии
- Python 3
- Работа с вводом данных (`input`, `float`)
- Форматирование строк (f-strings)
